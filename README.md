A node based video game engine.

Equipped with:

A batching Rendering engine that uses OpenGL 3.3, Capable of rendering orthonormal Sprites/ColorRectangles, it is possible to include prespective projection if needed.

A AABB Physics engine, Capable of treating , Rigid x Rigid | Rigid x Static | Body x Area | Body x Body | Body x Raycast.

Input handler, Capable of handling keyboard | Mouse.

No Audio Engine, very possbile to include using OpenAL.

This Engine was used to create the 2nd year's OOP video game project -> https://github.com/Just-Ab/Project-Second-Year-OOP
